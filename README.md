# EQ Buddy

Free tools for EverQuest players, driven by your EverQuest log files: stream overlays (roll leaderboard, loot pop-outs, combat numbers, quake alert, Govee lights, custom events) and **Tunnel Buddy**, an East Commonlands auction window with watch lists, price history and social-button writing.

## Download
Get the newest installer from the [latest release](https://github.com/CasualHaunter/eq-stream-hud/releases/latest): the file called `EQ-Buddy-Setup-<version>.exe`.

Windows may say "Windows protected your PC" because the installer is not code-signed. Click **More info**, then **Run anyway**. It installs for your user only (no administrator) and updates itself.
